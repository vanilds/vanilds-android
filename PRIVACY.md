# Privacy policy: Vani Santos (Android app)

_Last updated: 2026-11-27_

This app is a window onto the website https://vanilds.github.io (Vani Santos' portfolio and the
CreditDesk demo). It is a personal, non-commercial project.

## What the app itself collects

Nothing. The app has no analytics, no ads, no crash reporting and no tracking SDKs. It asks for
one permission, internet access, to load the website.

## The website inside the app

- **Portfolio pages** only show public information about the author.
- **CreditDesk demo** is a fictional back-office system with fictional customers. Signing in uses
  shared demo accounts provided on the page; do not enter real personal data. The demo stores the
  data you type (fictional customers, proposals and uploaded test documents) on the demo server
  (Amazon Web Services, us-east-1) so the demo works, and an audit log of actions taken with the
  demo accounts. Demo data may be reset or deleted at any time.
- Sign-in tokens are kept in the app's web storage only for your session.
- Files you choose with the file picker are sent only to the demo server, and only when you
  upload them.

No data is sold or shared with third parties, and nothing is used for advertising.

## Links

Links to other sites (LinkedIn, GitHub, ...) open in your browser and follow those sites' own
policies.
